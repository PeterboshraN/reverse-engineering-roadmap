## Week 2 — Assembly & Stack Basics

This week focused on understanding low level program execution through x86 assembly and stack behavior.

The goal was to move beyond decompiled code and start reading instructions directly.

---

## Topics Covered

- CPU registers and their roles
- Basic x86 instructions (`mov`, `add`, `sub`, `cmp`, `jmp`)
- Stack structure and stack frames
- Function calls and return behavior
- Arithmetic operations in assembly
- Conditional branching
- Loop structures at assembly level
